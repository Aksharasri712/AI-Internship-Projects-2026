# Deep Learning Project

## Project Name
Plant Disease Detection using CNN

## Objective
Build a deep learning model using Convolutional Neural Networks (CNN) to classify plant leaf diseases from images.

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Google Colab

## Deep Learning Concepts Used
- CNN (Convolutional Neural Networks)
- Image Classification
- Image Preprocessing
- Model Training and Evaluation

## Outcome
Successfully developed a CNN-based image classification model for detecting plant diseases.
